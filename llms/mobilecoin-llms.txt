# Full Service API

## Full Service API

- [Welcome!](https://mobilecoin.gitbook.io/full-service-api/readme.md): The Full Service API provides JSON RPC 2.0 endpoints for interacting with your MobileCoin transactions.
- [Overview](https://mobilecoin.gitbook.io/full-service-api/overview.md)
- [v2](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2.md)
- [Account](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account.md)
- [Account](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account.md): An account in the wallet. An account is associated with one AccountKey, containing a View keypair and a Spend keypair.
- [Create Account](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account/create_account.md): Create a new account in the wallet.
- [Import Account](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account/import_account.md): Import an existing account from the secret entropy.
- [Import Account Legacy](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account/import_account_from_legacy_root_entropy.md): Import an existing account from the secret entropy.
- [Get Accounts](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account/get_accounts.md): Get the details of all accounts in a given wallet.
- [Get Account Status](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account/get_account_status.md): Get the current status of a given account. The account status includes both the account object and the balance object.
- [Get Balance](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account/get-balance.md): Alias for get\_account\_status endpoint.
- [Update Account Name](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account/update_account_name.md): Rename an account.
- [Set Require Spend Subaddress](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account/set-require-spend-subaddress.md)
- [Remove Account](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account/remove_account.md): Remove an account from a given wallet.
- [Account Secrets](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account-secrets.md): The secret keys for an account. The account secrets are returned separately from other account information, to enable more careful handling of cryptographically sensitive information.
- [Export Account Secrets](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/account-secrets/export_account_secrets.md): Exporting the secret mnemonic an account is the only way to recover it when lost.
- [Address](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/address.md): An Address is a public address created from the Account Key. An Address contains a public View key and a public Spend key, as well as optional Fog materials, if the account is enabled for mobile.
- [Assign Address For Account](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/address/assign_address_for_account.md): Assign an address to a given account.
- [Get Address For Account](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/address/get_address_for_account.md): Get an assigned address by index for an account.
- [Get Addresses](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/address/get_addresses.md): Get assigned addresses for an account.
- [Get Address Status](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/address/get_address_status.md): Get the current balance for a given address. The response will have a map of the total values for each token\_id that is present at that address.
- [Verify Address](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/address/verify_address.md): Verify whether an address is correctly b58-encoded and return the address\_hash of the provided address.
- [View Only Account](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/view-only-account.md)
- [Import View Only Account](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/view-only-account/import_view_only_account.md): Create a view-only account by importing the private key from an existing account. Note: a single wallet cannot have both the regular and view-only versions of an account.
- [Create View Only Account Import Request](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/account/view-only-account/create_view_only_account_import_request.md)

- [Transaction](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/transaction.md): A MobileCoin Transaction consists of inputs which are spent in order to mint new outputs for the recipient.
- [Build Transaction](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/transaction/build_transaction.md): Build a transaction to confirm its contents before submitting it to the network.
- [Submit Transaction](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/transaction/submit_transaction.md): Submit a transaction for an account with or without recording it in the transaction log.
- [Build And Submit Transaction](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/transaction/build_and_submit_transaction.md): Sending a transaction is a convenience method that first builds and then submits a transaction.

- [Build Unsigned Transaction](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/transaction/build_unsigned_transaction.md): Build a unsigned transaction for use with the offline transaction signer
- [Build Unsigned Burn Transaction](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/transaction/build_unsigned_burn_transaction.md): Build a unsigned burn transaction for use with the offline transaction signer
- [Transaction Output TXO](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/txo.md): A TXO is a "Transaction Output." MobileCoin is a ledger built on the "Unspent Transaction Output" model (UTXO).

- [Get MobileCoin Protocol TXO](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/txo/get_mc_protocol_txo.md): Get the MobileCoin transaction TXO

- [Get Confirmations](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/transaction-confirmation/get_confirmations.md): A TXO constructed by this wallet will contain a confirmation number, which can be shared with the recipient to verify the association between the sender and this TXO.

- [Check Receiver Receipt Status](https://mobilecoin.gitbook.io/full-service-api/api-endpoints/v2/transaction/transaction-receipt/check_receiver_receipt_status.md): Check the status of a receiver receipt.
